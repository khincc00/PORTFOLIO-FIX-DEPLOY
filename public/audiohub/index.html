Versi 0.3.0

Routing audio profesional untuk macOS.

Atur setiap pasangan kanal input dan output dari satu jendela. Tangkap audio per aplikasi dengan opsi isolasi, efek per input, dan driver perangkat virtual AVHub v2 (tiga pasang) yang ikut terpasang otomatis.

Unduh untuk macOS (.dmg) Lihat fitur
macOS 14.4 atau lebih baru Apple Silicon dan Intel Installer ditandatangani Developer ID Driver hingga 768 kHz
Fitur

Semua jalur audio dalam satu tempat.

Dari mikrofon dan audio interface sampai aplikasi streaming, rekaman, dan panggilan. Setiap jalur bisa diatur dengan jelas.

Matriks routing per pasangan kanal

Hubungkan kanal input ke output mana pun. Setiap sel mengatur pasangan stereo, lengkap dengan gain dan mute.

Tangkap audio per aplikasi

Centang aplikasi yang sedang memutar audio, lalu jadikan audionya sumber input. Butuh macOS 14.4 ke atas dan izin Audio Capture dari macOS.

Isolasi aplikasi

Dengan isolasi, audio aplikasi tidak lagi terdengar di output asli. Suaranya hanya keluar lewat AudioHub, sesuai routing yang Anda atur.

Efek per input

Setiap input punya rantai pemrosesan dengan urutan yang jelas:

  • Noise gate
  • EQ tiga pita
  • Kompresor
  • Delay

Limiter per output

Batasi level di setiap output supaya tidak clipping ke aplikasi atau perangkat tujuan.

Plugin Audio Unit per input

Pasang satu plugin Audio Unit di setiap input, termasuk plugin bawaan Apple. Parameter plugin belum bisa diatur dari aplikasi.

Meter dan clip

Meter level real-time dengan indikator clip. Atur gain mikrofon sebelum sinyal mencapai batas.

Preset dan scene

Simpan konfigurasi sebagai preset, termasuk preset Reaper. Scene disimpan dalam format JSON versi 1.

Perangkat virtual

Driver AVHub v2 ikut terpasang.

Tidak perlu mencari driver pihak ketiga. Installer memasang aplikasi dan driver sekaligus, dengan tiga perangkat virtual stereo.

avhub_virtual1, avhub_virtual2, dan avhub_loopback

Tiga perangkat loopback stereo. Audio yang dikirim ke output salah satu perangkat bisa dibaca kembali dari input perangkat yang sama.

Dipakai di aplikasi lain

Pilih avhub_virtual sebagai input mikrofon atau sumber audio di aplikasi seperti OBS, dan AudioHub menjadi jalur routing-nya.

Spesifikasi driver

  • 13 sample rate, 8 kHz sampai 768 kHz
  • Buffer default 512 frame, rentang 16 sampai 4096
  • Latensi yang dilaporkan 0 frame
  • Kontrol volume dan mute, koreksi pitch, dan clock source
Baru di 0.3.0

Apa yang berubah di versi ini.

Routing dan perangkat

  • VC 1/2, VC 3/4, dan Loopback 1/2 bisa dipilih dari perangkat virtual apa pun yang terpasang
  • Tangkap audio per aplikasi (macOS 14.4 ke atas), dengan opsi isolasi
  • Loopback 1/2 sebagai pasangan virtual ketiga
  • Agregat AudioHub Aggregate tetap terlihat untuk DAW saat perangkat dibuka
  • Driver AVHub v2 ikut terpasang otomatis

Kontrol dan keamanan

  • Latensi buffer, input, dan output ditampilkan dalam milidetik
  • Volume dan bisukan untuk output perangkat keras
  • Konfirmasi sebelum menghapus atau menimpa preset
  • Fader dB yang bisa diatur dengan presisi, atau diketik langsung
  • Bahasa Inggris (default) dan Bahasa Indonesia
  • Engine tidak berjalan otomatis saat aplikasi dibuka

Pasang

Tiga langkah, lalu siap dipakai.

  1. Unduh dan buka DMG

    Buka AudioHub-0.3.0.dmg dari tombol unduh di halaman ini.

  2. Jalankan installer

    Dua kali klik Install AudioHub.pkg, lalu masukkan kata sandi administrator. Installer memasang aplikasi ke /Applications dan driver ke /Library/Audio/Plug-Ins/HAL.

  3. Pastikan perangkat virtual muncul

    Jalankan perintah berikut di Terminal. Hasilnya harus menampilkan avhub_virtual1, avhub_virtual2, dan avhub_loopback. Kalau belum muncul, restart Mac.

    system_profiler SPAudioDataType | grep avhub

Mencopot aplikasi: hapus /Applications/AudioHub.app dan /Library/Audio/Plug-Ins/HAL/AVHubDriver.driver dengan kata sandi administrator, lalu muat ulang layanan audio atau restart Mac.
